成功将容器系统的ID从字符串格式（`container_001`, `container_002`等）更新为数字格式（`1`, `2`, `3`等）。

## 更新的文件

### 1. 主要配置文件
- **`json/containers.json`**: ✅ 完成
  - 将所有容器的键从 `container_001-006` 更新为 `1-6`
  - 同步更新每个容器对象内的 `id` 字段

- **`public/data.json`**: ✅ 完成
  - 更新了fallback配置中的容器部分
  - 保持了与主配置文件的一致性

### 2. 前端代码
- **`src/App.tsx`**: ✅ 完成
  - 更新默认选中容器从 `container_002` 到 `2`
  - 容器选择逻辑自动兼容新的数字ID
