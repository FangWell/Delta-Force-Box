⏱️ 开启按钮倒计时功能测试

🎯 功能特性

  • 智能倒计时：按钮被锁定时显示剩余时间 "开启容器(3s)"
  • 视觉反馈：按钮置灰且不可点击，提供清晰的状态指示
  • 实时更新：倒计时每秒递减，精确显示剩余时间
  • 自动恢复：倒计时结束后按钮自动恢复正常状态
  • 防误操作：锁定期间完全阻止重复点击

🔍 触发场景

  • 点击"开启容器"后的操作锁定期间
  • 小游戏验证过程中
  • 开箱动画播放期间
  • 任何异步操作执行时

🧪 测试步骤

  1. 点击下方按钮打开主应用
  2. 选择"大保险箱"（已配置小游戏）
  3. 点击"开启容器"按钮
  4. 观察按钮显示变为"开启容器(3s)"并开始倒计时
  5. 尝试在倒计时期间点击按钮（应无响应）
  6. 等待倒计时结束，验证按钮恢复正常
🎯 预期效果：
• 按钮文本：开启容器 → 开启容器(3s) → 开启容器(2s) → 开启容器(1s) → 恢复正常
• 按钮状态：可点击 → 禁用置灰 → 可点击
• 用户交互：完全防止重复点击和误操作

// 倒计时状态管理 const [lockCountdown, setLockCountdown] = useState<number>(0); const countdownIntervalRef = useRef<NodeJS.Timeout | null>(null); // 启动倒计时 const startLockCountdown = useCallback((seconds: number = 3) => { clearCountdownTimer(); setLockCountdown(seconds); countdownIntervalRef.current = setInterval(() => { setLockCountdown(prev => { if (prev <= 1) { clearCountdownTimer(); return 0; } return prev - 1; }); }, 1000); }, [clearCountdownTimer]);
// 按钮文本计算 const getButtonText = useCallback(() => { if (openingState === OpeningState.OPENING) { return '开启中...'; } if (isOperationLocked && lockCountdown > 0) { return `开启容器(${lockCountdown}s)`; } return '开启容器'; }, [openingState, isOperationLocked, lockCountdown]);
